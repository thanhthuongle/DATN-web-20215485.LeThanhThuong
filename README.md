## Cài Đặt

1. **Clone Front-end**

   ```sh
   git https://github.com/thanhthuongle/HeyMoney-Web.git
   cd HeyMoney-Web
   ```
2. **Cài đặt các phụ thuộc**

   ```sh
   yarn install
   ```
3. **Khởi chạy Front-end**

   ```sh
   yarn dev
   ```
   Front-end sẽ được chạy tại `http://localhost:5174`.
